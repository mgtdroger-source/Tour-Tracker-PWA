TD Tour Entrant Tracker v1.05

Changes from v1.04:
- Installed/standalone mode now hides the whole App install section.
- Browser install card remains at the top when install is available.
- Adds Ignore Install button for users who do not want to install; it hides the card for the current browser session.
- Adds simple Help button and expandable help text.
- Uses Driver Surname wording.
- Help tells entrants to:
  1. Enter Tour No. and Driver Surname.
  2. Confirm Entrant.
  3. Start Tracking.
  4. Keep the tracker open and visible for the whole Tour.
  5. Reduce screen brightness to save battery.
  6. Watch Queue; it should normally return to 0 and clears automatically after signal returns.
- Explicit warning added that turning the screen off or backgrounding the PWA/browser may stop GPS tracking.
- Proven v1.04 tracking, queue/retry, install, reset and TT icon logic otherwise unchanged.
