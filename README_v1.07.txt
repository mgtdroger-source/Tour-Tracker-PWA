TD Tour Entrant Tracker v1.07

Changes from v1.05:
- Tour card now shows the configured Tour date range beside TOUR.
- TRACKING status now shows Available · Valid Date or Not Available · Invalid Date.
- Start Tracking is enabled only when the entrant is confirmed and the phone local date is one of the configured Tour dates.
- The app retains tourDates from the shared config link and also uses the uploaded event tourDates returned by Google.
- Date status refreshes while the app is open; tracking stops if the date becomes invalid.
- Existing Code.gs date validation remains the authoritative backend safeguard.
- Proven v1.05 tracking, queue/retry, install, reset and Help behaviour otherwise unchanged.
