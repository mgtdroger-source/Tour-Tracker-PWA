Help

Using the tracker

  1. Enter your Tour No. and Driver Surname.
  2. Select Confirm Entrant.
  3. Select Start Tracking.
  4. Keep the tracker open and visible for the whole Tour.
  5. Reduce screen brightness to save battery.
  6. Queue should normally return to 0. If signal is lost, it will rise and clear automatically when signal returns.

Important: turning the screen off or putting this PWA/browser page into the background may stop GPS tracking. Keep it visible while travelling.
