TD Tour Entrant Tracker v1.01

UI tidy-up from proven v1.00 tracking path.

Changes:
- Large Tracking Status card removed.
- Before start: one Start Tracking button.
- Once running: Start button is replaced by one compact live line:
  Sent / Queue · GPS total · Acc
- Sent = reports accepted by Google in the current tracking run.
- Queue = reports currently waiting on the phone.
- GPS = tracking reports generated in the current run.
- Acc = latest GPS accuracy.
- Only the Stop Tracking button remains while running.
- Detailed latitude/longitude and permanent 30-second status text removed.
- Queue/retry, 30-second reporting and Tour configuration logic unchanged.
