TD Tour Entrant Tracker v1.03

- Adds Reset App button at the bottom of the app.
- Reset clears tracker-specific Tour config, entrant identity, queued reports and sequence data.

- Adds in-app Install App button when the browser supplies the PWA install prompt.

- Installed/standalone mode does not show the install prompt card.
- Proven v1.02 30-second reporting, queue/retry and compact Queue · Total · Acc display retained.
